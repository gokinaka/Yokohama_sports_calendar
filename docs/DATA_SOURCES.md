Web検索(要約)経由でしか情報を得られなかったため、URLやページ構造が最新かどうかは
`scripts/inspect-sources.mjs` を実際に実行して確認する必要がある。

## 未解決事項(実装前に確認が必要)

1. Jリーグ公式のGoogle/Apple カレンダー機能が、認証不要で購読できる `.ics` / `webcal://` URLを
   クラブ単位で発行しているか。発行している場合、そのURLの命名規則。
2. TimeTree公開カレンダーを、TimeTreeアプリ/アカウントを介さずに自動取得する正規の方法があるか
   (非公式エクスポートツールはTimeTreeの利用規約上グレー〜違反の可能性があるため採用しない方針)。
3. 各サイトの利用規約・robots.txtがスクレイピング/自動取得/データの再配布を禁止していないか。
   `scripts/inspect-sources.mjs` は robots.txt の `User-agent: *` の Disallow を機械的に
   チェックするが、利用規約(Terms of Service)本文はrobots.txtでは分からないため、
   人間による確認が必要。
4. 横浜FCの2026年シーズンの所属カテゴリ(J1/J2)。

## 次のステップ

1. `.github/workflows/inspect-sources.yml` を実行し、各候補URLの実際のHTTPステータス・
   robots.txtの内容・JSON-LDや`.ics`リンクの有無をログで確認する。
2. 確認結果をもとに、ソースごとに「ICS購読で済ませる」か「HTML解析が必要」かを確定する。
3. 確定したソースについて `scripts/fetch/` 配下に実装し、`data/events.json` に統一スキーマで出力する。
