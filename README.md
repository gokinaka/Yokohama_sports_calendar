# 横浜近郊スポーツ観戦カレンダー

横浜近郊(神奈川県)のプロスポーツチームの試合日程を1つのカレンダーとして一覧できるようにする
Webアプリ。まずは全試合日程をカレンダー表示できることを目標とする。

## 現在のステータス

要件定義・データソース調査の段階。詳細は [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) を参照。

- 対象範囲: 神奈川県全体のプロスポーツチーム(サッカー/野球/バスケ/ラグビー)
- 表示形式: Webアプリ(ブラウザ)
- データ取得: 各チーム/リーグの公式データ(カレンダー配信・API)を優先し、
  無い場合のみ利用規約を確認した上でスクレイピングを検討する
- ホスティング想定: GitHub Pages(静的サイト) + GitHub Actionsによる定期データ更新

## 開発環境の制約

このリポジトリの初期開発はネットワークアクセスが制限されたリモート環境で行われており、
外部サイトのページ構造やICS配信URLを直接確認できなかった。そのため、まずは
`.github/workflows/inspect-sources.yml`(手動実行)で候補ソースの実データを取得・調査し、
その結果を踏まえて本実装を行う方針としている。

## ディレクトリ構成(予定含む)

```
config/sources.json          # 対象チームとデータソース候補
scripts/inspect-sources.mjs  # データソース調査スクリプト
docs/DATA_SOURCES.md          # データソース調査結果
.github/workflows/            # 調査・データ更新用ワークフロー
data/                          # 生成された試合日程データ(JSON)
site/                          # 静的フロントエンド(カレンダー表示)
```
